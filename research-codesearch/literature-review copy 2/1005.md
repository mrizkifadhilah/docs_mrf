# ARDEX (Arima, 1996)

*Sistem ini mengintegrasikan mekanisme temu kembali program otomatis dengan sintesis program induktif berbasis spesifikasi input-output untuk memfasilitasi penggunaan kembali komponen kode melalui pencarian pada labyrinthian program database.*

**Judul**
Automatic programming from a small number of examples, Fujitsu Scientific and Technical Journal, Fujitsu Limited, 1996

**Penulis**
Jun Arima (Kyoto University / Fujitsu Limited)

**Inti Paper**
Paper ini memperkenalkan sebuah sistem bernama ARDEX yang bertujuan untuk membantu pembuatan program secara otomatis. Cara kerjanya cukup unik: pengguna memberikan spesifikasi sederhana (misalnya contoh input dan output yang diinginkan), lalu sistem akan mencoba "mencari" (*retrieve*) program yang sudah ada di dalam database yang cocok dengan kebutuhan tersebut. Jika tidak ditemukan satu program yang sempurna, sistem akan mencoba menggabungkan beberapa potongan program lama atau membuat potongan kode baru untuk melengkapinya. Intinya, ARDEX menggabungkan konsep perpustakaan kode dengan kecerdasan buatan untuk merakit solusi perangkat lunak tanpa harus menulis kode dari nol.



**Baseline**
* **Synthesis of LISP Functions (Hardy, 1975):** Digunakan sebagai baseline awal untuk teknik pembuatan fungsi program secara otomatis dari contoh-contoh spesifik dalam bahasa pemrograman LISP.
* **Methodology for LISP Program Construction (Summers, 1977):** Digunakan sebagai baseline pembanding untuk proses konstruksi program melalui teknik induksi matematika yang lebih formal.
* **Software Reuse Framework (Krueger, 1992):** Digunakan sebagai landasan teori penggunaan kembali perangkat lunak (*software reuse*) untuk mengevaluasi efektivitas sistem dalam menghemat waktu pengembangan melalui pencarian komponen kode yang sudah ada.

**Keyword**
Automatic programming, Program retrieval, Software reuse, Program synthesis, ARDEX, Inductive logic programming.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini sangat relevan dan bisa dianggap sebagai salah satu pionir dalam riset **Code Search**. Berbeda dengan paper telekomunikasi yang hanya meminjam istilah "search", paper ini secara eksplisit membahas **Automatic Program Retrieval**. Ini sangat cocok dengan core riset Anda karena membahas bagaimana cara mencari kode yang sudah ada untuk membantu pengembang (atau dalam hal ini, membantu sistem otomatis) menyelesaikan tugas pemrograman.

**Perbedaan dengan Paper Sebelumnya**
1. **Objek:** Dibandingkan dengan paper **APS Synthesis (Kazimierczak, 1996)** yang fokus pada input bahasa alami, ARDEX lebih teknis karena menggunakan "contoh" (*examples*) atau spesifikasi teknis sebagai kunci pencarian.
2. **Metode:** Jika paper **SCA (Paul & Prakash, 1994)** fokus pada bahasa kueri aljabar untuk mencari teks, ARDEX lebih ke arah *semantic retrieval* (mencari berdasarkan perilaku atau fungsi program).
3. **Konteks:** Paper ini diterbitkan oleh Fujitsu, memberikan perspektif industri tentang bagaimana pencarian kode sumber diterapkan secara praktis untuk meningkatkan produktivitas dalam rekayasa perangkat lunak pada era 90-an.
