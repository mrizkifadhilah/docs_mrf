# MAPO (Xie & Pei, 2006)

*Framework ini mengintegrasikan mesin pencari kode sumber dengan algoritma frequent sequence mining untuk mengekstraksi pola penggunaan API yang tipikal dari repositori open-source guna memitigasi anomali kognitif pada dokumentasi yang kurang memadai.*

**Judul**
MAPO: Mining API usages from open source repositories, Proceedings - International Conference on Software Engineering (ICSE/MSR '06), ACM, 2006

**Penulis**
Tao Xie (North Carolina State University), Jian Pei (Simon Fraser University)

**Inti Paper**
Paper ini memperkenalkan sebuah alat bernama **MAPO** yang dirancang untuk membantu pemrogram memahami cara menggunakan API (antarmuka pemrograman aplikasi) yang kompleks. Seringkali, dokumentasi API tidak lengkap atau membingungkan. Pemrogram biasanya menggunakan mesin pencari kode untuk mencari contoh, namun hasil yang keluar seringkali terlalu banyak (ribuan baris kode) sehingga sulit dipelajari secara manual. MAPO bekerja dengan cara mengambil hasil pencarian kode tersebut, lalu menggunakan teknik "data mining" untuk menemukan pola urutan pemanggilan fungsi yang paling sering digunakan oleh pengembang lain. Alih-alih memberikan ribuan file, MAPO hanya memberikan daftar pendek pola penggunaan yang paling relevan dan ringkas.



**Bedah Abstrak Mendetail**
1. **"To improve software productivity, when constructing new software systems, developers often reuse existing class libraries or frameworks by invoking their APIs."**
   - *Maksud:* Penulis menyatakan bahwa untuk bekerja lebih produktif, pengembang biasanya menggunakan kembali perpustakaan kode yang sudah ada melalui pemanggilan API.
2. **"Those APIs, however, are often complex and not well documented, posing barriers for developers to use them in new client code."**
   - *Maksud:* Namun, API tersebut seringkali sangat rumit dan dokumentasinya buruk, sehingga menjadi hambatan bagi pengembang saat ingin menulis kode baru.
3. **"To get familiar with how those APIs are used, developers may search the Web using a general search engine... or use a source code search engine..."**
   - *Maksud:* Untuk belajar, pengembang biasanya mencari dokumen atau contoh kode melalui Google atau mesin pencari kode khusus.
4. **"Nevertheless, the number of returned source files is often large. It is difficult for developers to learn API usages from a large number of returned results."**
   - *Maksud:* Masalahnya, hasil pencarian tersebut sangat banyak jumlahnya, sehingga pengembang kesulitan menyaring informasi mana yang benar-benar penting.
5. **"In order to help developers understand API usages... we have developed an API usage mining framework and its supporting tool called MAPO."**
   - *Maksud:* Untuk mempermudah pemahaman tersebut, peneliti menciptakan sistem MAPO untuk melakukan penggalian data (mining) penggunaan API.
6. **"Given a query that describes a method, class, or package for an API, MAPO leverages the existing source code search engines to gather relevant source files and conducts data mining."**
   - *Maksud:* Pengguna cukup memasukkan nama fungsi atau kelas, lalu MAPO akan menggunakan mesin pencari yang ada untuk mengambil file kode dan mulai menambang pola-pola di dalamnya.
7. **"The mining leads to a short list of frequent API usages for developers to inspect."**
   - *Maksud:* Hasil akhir dari proses ini adalah daftar singkat berisi pola penggunaan yang paling sering muncul untuk ditinjau oleh pengembang.
8. **"MAPO currently consists of five components: a code search engine, a source code analyzer, a sequence preprocessor, a frequent sequence miner, and a frequent sequence post processor."**
   - *Maksud:* Penulis menjabarkan lima bagian teknis MAPO, mulai dari mesin pencari hingga pengolah hasil akhir.
9. **"The preliminary results show that the framework is practical for providing informative and succinct API usage patterns."**
   - *Maksud:* Hasil awal membuktikan bahwa sistem ini praktis dan mampu memberikan pola penggunaan API yang informatif namun tetap ringkas.

**Baseline**
* **Google / General Search Engines (2005):** Digunakan sebagai baseline pencarian informasi tradisional di web yang menghasilkan dokumen teks namun kurang spesifik dalam memberikan contoh kode yang dapat dieksekusi.
* **Koders / Source Code Search Engines (2005):** Digunakan sebagai baseline teknologi pencarian kode sumber yang ada saat itu untuk membuktikan bahwa sekadar "mencari" file tidak cukup tanpa proses "mining" hasil.
* **Mining Sequential Patterns (Agrawal & Srikant, 1995):** Digunakan sebagai baseline algoritma penambangan data sekuensial yang diadaptasi oleh MAPO untuk mengolah urutan pemanggilan API.
* **Mining Specifications (Ammons et al., 2002):** Digunakan sebagai baseline pembanding untuk teknik ekstraksi spesifikasi program dari jejak eksekusi (*runtime traces*), sementara MAPO fokus pada kode statis.

**Keyword**
Application Programming Interfaces (API), Mining software repositories, Code search, Frequent sequence mining, Program comprehension.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini adalah salah satu pionir dalam bidang **Semantic Code Search** dan **API Recommendation**. Paper ini tidak hanya membahas cara mencari kode, tetapi bagaimana mengolah hasil pencarian kode agar menjadi pengetahuan yang berguna (*actionable knowledge*). MAPO memberikan perspektif penting bagi riset Anda bahwa pencarian kode sumber adalah langkah awal, dan langkah berikutnya adalah perangkuman pola (*pattern summarization*) untuk membantu produktivitas pengembang.

**Perbedaan dengan Paper Sebelumnya**
1. **Pasca-Pencarian:** Berbeda dengan paper **CodeQuest (Hajiyev et al., 2006)** yang fokus pada kecepatan kueri, MAPO fokus pada apa yang harus dilakukan pengembang *setelah* hasil pencarian didapatkan.
2. **Pola vs. Unit:** Dibandingkan dengan **Component Reuse System (Washizaki & Fukazawa, 2005)** yang mencari unit komponen utuh, MAPO mencari **pola urutan** (langkah demi langkah) penggunaan suatu fungsi.
3. **Domain:** Berbeda dengan paper **Czech Spoken IR (Nouza et al., 2006)** yang mencari suara, MAPO murni beroperasi pada struktur teks kode sumber untuk meningkatkan pemahaman program.
