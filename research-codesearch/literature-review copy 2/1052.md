# SUITE-LifeCycle (Marri et al., 2009)

*Penelitian ini merumuskan model siklus hidup generik yang mengintegrasikan kapabilitas mesin pencari kode (CSE) untuk mengautomasi ekstraksi pola penggunaan API dan deteksi anomali guna meningkatkan penjaminan kualitas perangkat lunak.*

**Judul**
Improving Software quality via code searching and mining, 2009 ICSE Workshop on Search-Driven Development - Users, Infrastructure, Tools and Evaluation (SUITE 2009), IEEE Computer Society/ACM, 2009

**Penulis**
Madhuri R. Marri, Suresh Thummalapenta, Tao Xie (North Carolina State University, Amerika Serikat)

**Inti Paper**
Paper ini menyoroti bahwa penggunaan mesin pencari kode (*Code Search Engine* - CSE) saat ini masih sangat terbatas hanya untuk mencari contoh kode sederhana. Peneliti mengusulkan sebuah **model siklus hidup (life-cycle model)** yang lebih luas untuk meningkatkan kualitas perangkat lunak dengan memanfaatkan CSE di berbagai tahap pengembangan. Model ini membantu pengembang dalam tiga tugas utama: menemukan contoh penggunaan API yang benar, mendeteksi kesalahan umum yang sering dilakukan orang lain, dan memverifikasi apakah kode yang dibuat sudah sesuai dengan standar komunitas. Dengan mengikuti model ini, pengembang tidak hanya "menyalin" kode, tetapi menggunakan informasi dari jutaan baris kode di internet untuk membuat program yang lebih stabil dan minim kesalahan.



**Bedah Abstrak Mendetail**
1. **"Enormous amount of open source code is available on the Internet and various code search engines (CSE) are available to serve as a means for searching in open source code."**
   - *Maksud:* Saat ini ada banyak sekali kode gratis (open source) di internet dan tersedia berbagai mesin pencari khusus kode untuk mencarinya.
2. **"However, usage of CSEs is often limited to simple tasks such as searching for relevant code examples."**
   - *Maksud:* Namun, penggunaan mesin pencari kode tersebut biasanya masih terbatas pada tugas mudah seperti mencari contoh potongan kode saja.
3. **"In this paper, we present a generic life-cycle model that can be used to improve software quality by exploiting CSEs."**
   - *Maksud:* Dalam makalah ini, peneliti memperkenalkan sebuah model proses kerja (siklus hidup) yang bisa meningkatkan kualitas aplikasi dengan memanfaatkan mesin pencari kode secara maksimal.
4. **"We present three example software development tasks that can be assisted by our life-cycle model and show how these three tasks can contribute to improve the software quality."**
   - *Maksud:* Peneliti memberikan tiga contoh pekerjaan dalam pembuatan aplikasi yang bisa dibantu oleh model ini dan menjelaskan bagaimana hal itu membuat aplikasi jadi lebih bagus.
5. **"We also show the application of our life-cycle model with a preliminary evaluation."**
   - *Maksud:* Peneliti juga menunjukkan bagaimana model ini dijalankan melalui sebuah uji coba awal.

**Baseline**
* **PARSEWeb (Thummalapenta & Xie, 2007):** Digunakan sebagai baseline alat bantu pencarian kode yang menyarankan urutan pemanggilan API dari web untuk menyelesaikan masalah penggunaan library.
* **Jungloid Mining (Mandelin et al., 2005):** Digunakan sebagai baseline teknik penambangan struktur kode (*jungloids*) untuk membantu navigasi API yang kompleks melalui sintesis kode.
* **Sourcerer (Bajracharya et al., 2006):** Digunakan sebagai baseline infrastruktur mesin pencari kode berbasis struktur untuk mendukung pencarian aset perangkat lunak skala besar.
* **Neglected Conditions Detection (Chang et al., 2007):** Digunakan sebagai baseline untuk membandingkan bagaimana pencarian kode dapat membantu menemukan kondisi logika yang sering terlewatkan oleh pengembang.

**Keyword**
Code search engine, Life cycle model, Open-source code, Software Quality, Search-driven development.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini sangat penting bagi riset Anda karena memberikan **kerangka kerja strategis**. Jika riset Anda bertujuan untuk memposisikan "Code Search" sebagai bagian integral dari pengembangan perangkat lunak (bukan sekadar alat tambahan), paper ini menyediakan "Life-cycle Model" yang bisa Anda jadikan referensi. Paper ini membantu memperluas cakupan riset Anda dari sekadar "bagaimana mencari" menjadi "bagaimana pencarian kode berdampak pada kualitas perangkat lunak secara keseluruhan".

**Perbedaan dengan Paper Sebelumnya**
1. **Fokus Model:** Berbeda dengan paper **Sourcerer (2009)** yang fokus pada infrastruktur teknis mesin pencari, paper ini fokus pada **proses/metodologi** penggunaan mesin pencari tersebut oleh manusia.
2. **Tujuan Kualitas:** Jika paper **SNIFF (2009)** fokus pada kemudahan kueri, paper ini fokus pada **penjaminan kualitas** (*Quality Assurance*) melalui pencarian kode.
3. **Sifat Makalah:** Dibandingkan dengan **MAPO (2009)** yang merupakan solusi teknis untuk API, paper ini bersifat **konseptual dan prosedural**, memberikan panduan tahap-tahap integrasi pencarian kode dalam SDLC (*Software Development Life Cycle*).
