# SemmleCode (Verbaere et al., 2007)

*SemmleCode mengintegrasikan mesin kueri berorientasi objek berbasis logika deskriptif ke dalam lingkungan Eclipse untuk memfasilitasi penelusuran semantik, audit konvensi pengkodean, dan ekstraksi metrik perangkat lunak secara deklaratif.*

**Judul**
Improve software quality with SemmleCode - An eclipse plugin for semantic code search, 22nd International Conference on Object-Oriented Programming Systems, Languages, and Applications (OOPSLA 2007), ACM, 2007

**Penulis**
Mathieu Verbaere, Elnar Hajiyev, Oege de Moor (Semmle Ltd, Oxford, United Kingdom)

**Inti Paper**
Paper ini memperkenalkan **SemmleCode**, sebuah alat bantu (*plugin*) gratis untuk Eclipse yang mengubah cara pengembang berinteraksi dengan kode mereka. Jika biasanya pengembang mencari kode hanya berdasarkan teks atau nama file, SemmleCode memungkinkan mereka melakukan "pencarian semantik". Artinya, pengembang bisa mengajukan pertanyaan rumit seperti "cari semua fungsi yang tidak memiliki dokumentasi" atau "temukan variabel yang berpotensi menyebabkan bug". Semua tugas ini (mencari bug, menghitung metrik, mengecek aturan gaya penulisan) diperlakukan sebagai kueri terhadap basis data kode. Hasilnya bisa ditampilkan dalam bentuk tabel, grafik, atau pohon, dan semuanya terhubung langsung ke baris kode aslinya.



**Bedah Abstrak Mendetail**
1. **"Navigate code, find bugs, compute metrics, check style rules, and enforce coding conventions in Eclipse with Semmle-Code."**
   - *Maksud:* Peneliti menjabarkan kegunaan utama SemmleCode yaitu untuk menavigasi kode, mencari kesalahan program (bug), menghitung data statistik kode (metrik), mengecek aturan penulisan, dan memastikan standar pengkodean dipatuhi di dalam Eclipse.
2. **"SemmleCode is a new free Eclipse plugin that allows you to phrase ini these tasks as queries over the codebase - it thus takes the search facilities in Eclipse to a whole new level."**
   - *Maksud:* Alat ini adalah *plugin* baru yang memungkinkan semua tugas teknis tersebut dilakukan dalam bentuk kueri (pertanyaan terstruktur) terhadap kumpulan kode, sehingga meningkatkan kemampuan pencarian standar Eclipse secara signifikan.
3. **"A large library of queries for common operations is provided, including metrics and Java EE style rules."**
   - *Maksud:* SemmleCode sudah menyediakan banyak daftar pertanyaan siap pakai untuk tugas-tugas umum, termasuk untuk menghitung kerumitan kode dan aturan khusus untuk standar Java EE.
4. **"Query results can be displayed as a tree view, a table view, in the problem view, as charts or graphs, all with links to the source code."**
   - *Maksud:* Hasil dari pencarian kueri tersebut bisa dilihat dalam berbagai format visual (tabel, grafik, atau daftar masalah) yang semuanya bisa diklik untuk langsung menuju ke baris kode yang dimaksud.

**Baseline**
* **Eclipse Standard Search (IBM, 2001):** Digunakan sebagai baseline fungsionalitas pencarian bawaan Eclipse yang hanya terbatas pada pencarian teks (*string*) dan referensi Java sederhana.
* **CodeQuest (Hajiyev et al., 2006):** Digunakan sebagai baseline teknologi kueri berbasis Datalog yang menjadi cikal bakal bahasa kueri berorientasi objek (.ql) yang diterapkan dalam SemmleCode.
* **Checkstyle/PMD (Standard Tools):** Digunakan sebagai baseline fungsionalitas pemeriksaan aturan gaya penulisan dan konvensi kode secara statis.

**Keyword**
Code queries, Semantic code search, Coding conventions, Metrics, Object-oriented query language, Software quality.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini sangat krusial jika riset Anda menyentuh aspek **"Semantic Code Search"** atau pencarian kode berbasis logika. SemmleCode (yang kini menjadi bagian dari GitHub CodeQL) membuktikan bahwa pencarian kode tidak hanya tentang mencari teks, tetapi tentang menanyakan properti struktural dan logika dari program. Ini adalah fondasi penting untuk riset yang ingin meningkatkan akurasi pencarian kode di lingkungan pengembangan profesional.

**Perbedaan dengan Paper Sebelumnya**
1. **Model Kueri:** Berbeda dengan paper **Sourcerer (Bajracharya et al., 2006)** yang menggunakan database relasional standar, SemmleCode menggunakan bahasa kueri khusus yang berorientasi objek untuk kemudahan ekspresi logika kode.
2. **Integrasi IDE:** Jika paper **CodeGenie (2007)** berfokus pada pencarian kode dari internet untuk *reuse*, SemmleCode berfokus pada **pencarian internal** pada basis kode proyek sendiri untuk pemeliharaan dan kualitas.
3. **Representasi Visual:** Dibandingkan dengan **Reference Vectors (Ohno & Murao, 2007)** yang hanya menghasilkan angka kemiripan, SemmleCode menghasilkan wawasan mendalam seperti grafik dependensi dan laporan kepatuhan gaya penulisan kode.
