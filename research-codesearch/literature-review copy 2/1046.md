# SNIFF (Chatterjee et al., 2009)

*Sistem ini mengintegrasikan dokumentasi API ke dalam kode sumber yang tidak teranotasi untuk memfasilitasi temu kembali kode berbasis kueri bahasa alami (free-form queries) melalui mekanisme persimpangan berbasis tipe (type-based intersection).*

**Judul**
SNIFF: A search engine for java using free-form queries, 12th International Conference on Fundamental Approaches to Software Engineering (FASE 2009), Springer, 2009

**Penulis**
Shaunak Chatterjee, Sudeep Juvekar, Koushik Sen (University of California, Berkeley, Amerika Serikat)

**Inti Paper**
Paper ini memperkenalkan **SNIFF**, sebuah mesin pencari kode yang memungkinkan pengembang mencari contoh penggunaan perpustakaan (*library*) Java hanya dengan menggunakan bahasa Inggris sehari-hari. Masalah utama saat ini adalah pengembang sering terjebak dalam kurva pembelajaran yang curam saat mencoba memahami API yang kompleks. Pencarian di Google biasanya menghasilkan ribuan halaman yang harus dibaca secara manual, sementara alat pencari kode lain seringkali mewajibkan pengguna sudah tahu jenis data (tipe API) yang dicari. SNIFF bekerja dengan cara yang unik: ia meminjam dokumentasi resmi dari metode perpustakaan untuk memberi "makna" pada kode-kode yang biasanya sulit dipahami. Selain itu, SNIFF secara cerdas menggabungkan berbagai cuplikan kode yang serupa menggunakan logika berbasis tipe data agar hasil yang diberikan sangat ringkas dan relevan bagi pengembang.



**Bedah Abstrak Mendetail**
1. **"Reuse of existing libraries simplifies software development efforts."**
   - *Maksud:* Menggunakan kembali perpustakaan kode yang sudah ada mempermudah pekerjaan pembuatan perangkat lunak.
2. **"However, these libraries are often complex and reusing the APIs in the libraries involves a steep learning curve."**
   - *Maksud:* Sayangnya, perpustakaan ini seringkali rumit dan mempelajarinya butuh waktu yang sangat lama.
3. **"A programmer often uses a search engine such as Google to discover code snippets involving library usage to perform a common task."**
   - *Maksud:* Pengembang biasanya memakai Google untuk mencari contoh kode demi menyelesaikan tugas tertentu.
4. **"A problem with search engines is that they return many pages that a programmer has to manually mine to discover the desired code."**
   - *Maksud:* Masalahnya, Google memberikan terlalu banyak hasil sehingga pengembang harus menyisirnya satu per satu secara manual.
5. **"Recent research efforts have tried to address this problem by automating the generation of code snippets from user queries. However, these queries need to have type information and therefore require the user to have a partial knowledge of the APIs."**
   - *Maksud:* Penelitian terbaru mencoba mengotomatisasi pencarian ini, tapi kuerinya seringkali mengharuskan pengembang sudah tahu info teknis/tipe API-nya, yang justru belum mereka ketahui.
6. **"We propose a novel code search technique, called SNIFF, which retains the flexibility of performing code search in plain English, while obtaining a small set of relevant code snippets to perform the desired task."**
   - *Maksud:* Peneliti mengusulkan SNIFF yang tetap fleksibel (bisa pakai bahasa Inggris biasa) tapi memberikan hasil yang sangat fokus dan ringkas.
7. **"Our technique is based on the observation that the library methods that a user code calls are often well-documented. We use the documentation of the library methods to add plain English meaning to an otherwise undocumented user code."**
   - *Maksud:* Teknik ini memanfaatkan fakta bahwa dokumentasi perpustakaan biasanya lengkap. SNIFF menyalin teks dokumentasi tersebut ke dalam kode mentah agar kode tersebut bisa dicari menggunakan kata-kata manusia.
8. **"Another novel contribution of our technique is that we take a type-based intersection of the candidate code snippets obtained from a query search to generate a set of small and highly relevant code snippets."**
   - *Maksud:* Kontribusi lainnya adalah penggunaan "persimpangan berbasis tipe" untuk menyatukan potongan kode yang mirip menjadi satu hasil yang paling akurat.
9. **"We have implemented SNIFF for Java and have performed evaluations and user studies to demonstrate the utility of SNIFF."**
   - *Maksud:* Sistem ini dibuat untuk Java dan sudah diuji coba kepada pengguna langsung untuk membuktikan kegunaannya.

**Baseline**
* **Strathcona (Holmes & Murphy, 2005):** Digunakan sebagai baseline untuk alat pemberi rekomendasi kode yang berbasis pada struktur konteks kode yang sedang dikerjakan pengembang.
* **Google/Online Search Engines (Page et al., 1998):** Digunakan sebagai pembanding untuk menunjukkan bahwa pencarian teks umum di web tidak seefisien pencarian khusus kode milik SNIFF.
* **DECKARD (Jiang et al., 2007):** Digunakan sebagai baseline dalam hal deteksi kemiripan kode berbasis pohon sintaksis untuk membandingkan akurasi pengelompokan cuplikan kode.

**Keyword**
Code search, Free-form queries, Library documentation, Java, Type-based intersection.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini adalah referensi klasik yang sangat penting jika riset Anda berfokus pada **"Natural Language Code Search"**. SNIFF menjawab tantangan bagaimana menghubungkan bahasa manusia (kueri) dengan bahasa mesin (kode) melalui jembatan **dokumentasi API**. Jika riset Anda bertujuan mempermudah pengembang pemula dalam mencari kode tanpa harus tahu istilah teknis API-nya, maka SNIFF adalah pondasi teori yang harus Anda kutip.

**Perbedaan dengan Paper Sebelumnya**
1. **Kueri Bahasa Alami:** Berbeda dengan paper **PARSEWeb (2007)** yang kuerinya kaku (Source $\rightarrow$ Destination), SNIFF mengizinkan kueri bebas seperti "cara membaca file".
2. **Sumber Informasi:** Jika paper **Sourcerer (2009)** mengandalkan topik teks dari kode itu sendiri, SNIFF menambahkan informasi dari **dokumentasi luar** untuk memperkaya makna kode.
3. **Penyajian Hasil:** Dibandingkan dengan **CodeGenie (2007)** yang hanya mengandalkan tes, SNIFF melakukan **interseksi berbasis tipe** untuk menyederhanakan ribuan hasil pencarian menjadi beberapa cuplikan yang paling mewakili solusi.
