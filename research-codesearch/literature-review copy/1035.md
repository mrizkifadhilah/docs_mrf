# SpotWeb (Thummalapenta & Xie, 2008)

*Sistem ini mengintegrasikan mekanisme penambangan repositori kode sumber terbuka berskala internet melalui mesin pencari kode untuk mengidentifikasi hotspot API berdasarkan frekuensi instansiasi dan penggunaan fungsional dalam ekosistem perangkat lunak.*

**Judul**
SpotWeb: Detecting framework Hotspots via mining open source repositories on the web, 5th International Workshop on Mining Software Repositories (MSR 2008), IEEE Computer Society/ACM, 2008

**Penulis**
Suresh Thummalapenta, Tao Xie (North Carolina State University, Amerika Serikat)

**Inti Paper**
Paper ini memperkenalkan **SpotWeb**, sebuah alat yang membantu pemrogram memahami cara menggunakan *library* atau *framework* baru (seperti JUnit atau Log4j) dengan cara mencari bagian mana yang paling sering digunakan oleh orang lain di internet. Bagian yang sering digunakan ini disebut "**Hotspots**" (titik panas). Masalahnya, banyak *framework* yang rumit dan dokumentasinya kurang jelas. SpotWeb bekerja dengan menggunakan mesin pencari kode (CSE) untuk mengumpulkan jutaan contoh kode dari web, lalu menganalisisnya secara otomatis untuk menemukan API (perintah) mana yang paling populer. Dengan mengetahui *hotspots* ini, pemrogram punya titik awal yang jelas untuk mulai belajar tanpa harus membaca seluruh dokumentasi yang membosankan.



**Bedah Abstrak Mendetail**
1. **"The essentials of modern software development (such as low cost and high efficiency) demand software developers to make intensive reuse of existing open source frameworks or libraries... available on the web."**
   - *Maksud:* Pengembangan perangkat lunak modern menuntut kecepatan dan biaya rendah, sehingga pemrogram harus sering menggunakan kembali kode/perpustakaan yang sudah ada di internet.
2. **"However, developers often face challenges in reusing ini these frameworks due to several factors such as the complexity and lack of proper documentation."**
   - *Maksud:* Namun, pemrogram sering kesulitan memakai perpustakaan tersebut karena terlalu rumit atau dokumentasinya tidak lengkap.
3. **"In this paper, we propose a code-search-engine-based approach that tries to detect hotspots in a given framework by mining code examples gathered from open source repositories available on the web..."**
   - *Maksud:* Peneliti mengusulkan cara menggunakan mesin pencari kode untuk menemukan "hotspots" (bagian terpenting) dengan menambang contoh kode dari berbagai sumber di internet.
4. **"...these hotspots are the APIs that are frequently reused."**
   - *Maksud:* Hotspots didefinisikan sebagai bagian dari perintah program (API) yang paling sering dipakai berulang kali oleh banyak orang.
5. **"Hotspots can serve as starting points for developers in understanding and reusing the given framework."**
   - *Maksud:* Bagian populer ini bisa menjadi panduan awal bagi pemrogram untuk mengerti cara kerja perpustakaan tersebut.
6. **"We developed a tool, called SpotWeb, for frameworks or libraries written in Java and conducted two case studies with two open source frameworks JUnit and Log4j."**
   - *Maksud:* Peneliti membuat aplikasi bernama SpotWeb untuk bahasa Java dan mengujinya pada dua alat populer, yaitu JUnit dan Log4j.
7. **"We also show that the detected hotspots of Log4j and JUnit are consistent with their respective documentations."**
   - *Maksud:* Hasilnya menunjukkan bahwa bagian yang dianggap penting oleh SpotWeb ternyata memang benar-benar bagian penting menurut buku panduan resminya.

**Baseline**
* **MAPO (Xie & Pei, 2006):** Digunakan sebagai baseline metode penambangan penggunaan API (*API usage mining*) dari repositori kode sumber terbuka untuk merekomendasikan pola penggunaan kode.
* **PARSEWeb (Thummalapenta & Xie, 2007):** Digunakan sebagai baseline asisten pemrogram yang menyarankan urutan pemanggilan metode (*method sequences*) melalui pencarian kode di internet.
* **Mendonça (Mendonça et al., 2005):** Digunakan sebagai baseline studi tentang bantuan instansiasi *framework* yang berorientasi pada aspek dan alat pendukungnya.

**Keyword**
Code reuse, Code search engine, Hotspots, API mining, Open source repositories.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini sangat relevan jika riset "Code Search" Anda berfokus pada **rekomendasi kode** atau **pemahaman kode (code understanding)**. SpotWeb membuktikan bahwa mesin pencari kode tidak hanya berguna untuk mencari potongan kode spesifik, tetapi juga bisa digunakan sebagai sumber data besar (*Big Data*) untuk menemukan tren penggunaan teknologi. Ini membantu riset Anda menjelaskan bagaimana hasil pencarian kode bisa diprioritaskan berdasarkan tingkat kepopulerannya di komunitas global.

**Perbedaan dengan Paper Sebelumnya**
1. **Tujuan Analisis:** Berbeda dengan paper **Sourcerer (2006)** yang fokus pada infrastruktur pencarian, SpotWeb fokus pada **interpretasi hasil pencarian** untuk menentukan bagian kode yang paling krusial (*hotspots*).
2. **Output:** Jika paper **PARSEWeb (2007)** menghasilkan solusi berupa jalur pemanggilan fungsi (A ke B), SpotWeb menghasilkan **daftar prioritas API** yang harus dipelajari terlebih dahulu oleh pemrogram.
3. **Validasi:** Dibandingkan dengan **CodeGenie (2007)** yang memvalidasi hasil lewat eksekusi tes, SpotWeb memvalidasi hasilnya dengan **membandingkannya dengan dokumentasi resmi** untuk memastikan akurasi deteksi tingkat kepentingan API.
