# ISCS (Gallardo-Valencia & Sim, 2009)

*Makalah posisi ini mengonseptualisasikan Internet-Scale Code Search sebagai disiplin multidisiplin yang mensinergikan teknik temu kembali informasi, pemahaman program (program comprehension), dan strategi penggunaan kembali perangkat lunak untuk mengatasi beban kognitif pada repositori berskala masif.*

**Judul**
Internet-Scale Code Search, 2009 ICSE Workshop on Search-Driven Development - Users, Infrastructure, Tools and Evaluation (SUITE 2009), IEEE Computer Society, 2009

**Penulis**
Rosalva E. Gallardo-Valencia, Susan Elliott Sim (University of California, Irvine, Amerika Serikat)

**Inti Paper**
Paper ini mendefinisikan sebuah bidang baru yang disebut **Internet-Scale Code Search (ISCS)**. Peneliti menjelaskan bahwa mencari kode di internet bukan sekadar masalah teknis "mencari teks" menggunakan mesin pencari biasa. Karena jumlah kode sumber terbuka (*open source*) di internet meledak sangat banyak, pengembang membutuhkan solusi yang lebih cerdas. Peneliti berargumen bahwa untuk memecahkan masalah pencarian kode skala besar, kita harus menggabungkan tiga bidang: teknik pencarian informasi (IR), pemahaman kode oleh manusia (*program comprehension*), dan cara memakai kembali kode (*software reuse*). Paper ini menjadi landasan teori mengapa kita butuh alat pencari kode yang didesain khusus, bukan sekadar Google yang dipaksakan untuk membaca kode.



**Bedah Abstrak Mendetail**
1. **"Internet-Scale Code Search is the problem of finding source on the Internet."**
   - *Maksud:* Pencarian Kode Skala Internet adalah persoalan tentang bagaimana cara menemukan kode sumber di seluruh jagat internet.
2. **"Developers are typically searching for code to reuse as-is on a project or as a reference example."**
   - *Maksud:* Pengembang biasanya mencari kode untuk dua tujuan: langsung dipakai di proyek mereka atau sekadar dijadikan contoh referensi.
3. **"This phenomenon has emerged due to the increasing availability and quality of open source and resources on the web."**
   - *Maksud:* Fenomena pencarian ini muncul karena semakin banyaknya jumlah dan semakin bagusnya kualitas kode sumber terbuka yang tersedia di web.
4. **"Solutions to this problem will involve more than the simple application of information retrieval techniques or a scaling-up of tools for code search."**
   - *Maksud:* Solusi untuk masalah ini tidak cukup hanya dengan menerapkan teknik pencarian informasi biasa atau sekadar memperbesar kapasitas alat pencari yang sudah ada.
5. **"Instead, new, purpose-built solutions are needed that draw on results from these areas, as well as program comprehension and software reuse."**
   - *Maksud:* Sebaliknya, dibutuhkan solusi baru yang dibangun khusus dengan mengambil ilmu dari bidang pencarian data, pemahaman program (cara manusia mengerti kode), dan teknik penggunaan kembali perangkat lunak.

**Baseline**
* **Software Reuse (Krueger, 1992):** Digunakan sebagai baseline teori klasik mengenai penggunaan kembali perangkat lunak untuk membedakan antara teknik pencarian kode modern dengan metode pustaka komponen tradisional.
* **Information Retrieval (Manning et al., 2008):** Digunakan sebagai baseline teknik temu kembali informasi standar untuk membuktikan bahwa pencarian kode memerlukan pendekatan yang lebih spesifik daripada sekadar pencocokan teks dokumen.
* **Program Comprehension Theories (Storey, 2006):** Digunakan sebagai baseline untuk memahami bagaimana alat pencari harus mendukung proses kognitif pengembang dalam memahami kode yang asing.
* **Archetypal Source Code Searches (Sim et al., 1998):** Digunakan sebagai baseline survei perilaku pengembang dalam mencari kode untuk memvalidasi kebutuhan akan infrastruktur pencarian skala internet.

**Keyword**
Internet-Scale Code Search, Open source, Program comprehension, Software reuse, Search-driven development.

**Perbedaan dengan Paper Sebelumnya**
1. **Sifat Makalah:** Berbeda dengan paper **Sourcerer (2009)** yang memberikan solusi teknis (infrastruktur), paper ini adalah *position paper* yang memberikan **kerangka pikir (framework)** konseptual.
2. **Cakupan:** Jika paper **MAPO (2009)** sangat spesifik pada API, paper ini mencakup seluruh ekosistem pencarian kode di internet sebagai sebuah disiplin ilmu.
3. **Perspektif Manusia:** Dibandingkan dengan **SNIFF (2009)** yang fokus pada kueri, paper ini menekankan pada **aspek psikologis** pengembang (bagaimana mereka memahami kode setelah menemukannya).
