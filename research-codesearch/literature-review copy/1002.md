# SCRUPLE Discussion (Devanbu, 1995)

*Komentar teknis ini mengevaluasi taksonomi sistem temu kembali kode sumber dengan membandingkan ekspresivitas kueri berbasis pola pada framework SCRUPLE terhadap sistem manipulasi pohon sintaksis dan generator program yang telah ada sebelumnya.*

**Judul**
On “A Framework for Source Code Search Using Program Patterns”, IEEE Transactions on Software Engineering, IEEE, 1995

**Penulis**
Prem Thomas Devanbu (Nokia Bell Labs)

**Inti Paper**
Paper ini merupakan sebuah tanggapan kritis terhadap penelitian sebelumnya (SCRUPLE oleh Paul & Prakash). Penulis setuju bahwa mencari kode sumber menggunakan pola program adalah solusi yang sangat dibutuhkan oleh pengembang perangkat lunak. Namun, paper ini menunjukkan bahwa ada banyak teknologi lain yang sudah ada (seperti sistem manipulasi pohon kode dan generator program) yang sebenarnya bisa melakukan tugas serupa tetapi tidak disebutkan dalam penelitian SCRUPLE. Devanbu menjelaskan bagaimana sistem-sistem lama tersebut berhubungan dengan metode pencarian pola modern, sehingga riset tentang pencarian kode memiliki konteks sejarah dan teknis yang lebih lengkap dalam dunia rekayasa perangkat lunak.

**Baseline**
* **SCRUPLE Framework (Paul & Prakash, 1994):** Digunakan sebagai objek evaluasi utama yang menawarkan pencarian kode berbasis pola menggunakan *finite state machine*.
* **Gandalf Environment (Habermann, 1986):** Digunakan sebagai baseline untuk lingkungan pengembangan perangkat lunak terintegrasi yang mendukung manipulasi struktur kode secara langsung melalui *syntax-directed editing*.
* **A* Language (Ladd, 1994):** Digunakan sebagai pembanding bahasa pemrograman yang khusus dirancang untuk mengimplementasikan prosesor bahasa dan pencarian pola pada struktur kode.
* **The Synthesizer Generator (Reps, 1984):** Digunakan sebagai baseline sistem untuk membangun editor yang sadar akan tata bahasa (language-aware), yang menjadi dasar dari sistem pencarian kode berbasis struktur.

**Keyword**
Source code search, Program patterns, Software development environments, Program understanding, Query languages.
