# SCA Algebra (Paul & Prakash, 1996)

*Penelitian ini mengusulkan Source Code Algebra (SCA) sebagai formalisme kueri aljabar berbasis objek yang mengintegrasikan analisis struktur sintaksis dan aliran kontrol untuk mengoptimalkan ekspresivitas serta efisiensi temu kembali informasi pada basis data program.*

**Judul**
A query algebra for program databases, IEEE Transactions on Software Engineering, IEEE, 1996

**Penulis**
Santanu Paul (IBM Thomas J. Watson Research Center), Atul Prakash (University of Michigan)

**Inti Paper**
Paper ini memperkenalkan **Source Code Algebra (SCA)**, sebuah metode canggih untuk mencari dan menganalisis kode sumber dengan cara yang mirip dengan kueri pada database (seperti SQL, namun khusus untuk kode). Masalah yang diselesaikan adalah sulitnya memahami struktur program besar hanya dengan pencarian teks biasa. Peneliti membangun basis data berorientasi objek untuk menyimpan kode sumber, lalu menggunakan ekspresi aljabar untuk melakukan pencarian yang kompleks, seperti melacak aliran sumber daya, aliran kontrol, hingga metrik kode. Dengan SCA, pengembang dapat mencari fungsi atau variabel bukan hanya berdasarkan namanya, tetapi juga berdasarkan hubungannya dengan komponen lain dalam sistem, sehingga memudahkan proses pemeliharaan dan pemahaman program secara menyeluruh.



**Baseline**
* **The C Information Abstraction System (CIA) (Chen et al., 1990):** Digunakan sebagai baseline sistem ekstraksi relasional untuk kode C, di mana SCA mengunggulinya dengan kemampuan menangani data berorientasi objek dan aliran kontrol yang lebih fleksibel.
* **Concept Assignment Problem (Biggerstaff, 1993):** Digunakan sebagai baseline metodologi untuk memahami bagaimana kueri aljabar dapat membantu memetakan kode tingkat rendah ke konsep desain tingkat tinggi dalam aktivitas *reverse engineering*.
* **Attributed Dependency Graphs (Al-Zoubi, 1995):** Digunakan sebagai pembanding untuk teknik visualisasi dan analisis perubahan program berbasis graf yang menjadi dasar pembentukan kueri struktural pada SCA.

**Keyword**
Source Code Algebra (SCA), Program query language, Program understanding, Reverse engineering, Object-oriented database, Query optimization.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Ini adalah salah satu paper "Holy Grail" dalam sejarah riset **Code Search**. Paper ini secara eksplisit mendefinisikan bagaimana pencarian kode sumber harus dilakukan menggunakan landasan matematika yang kuat (aljabar). Jika riset Anda membahas tentang *Structural Code Search* atau bagaimana membangun mesin pencari yang memahami semantik hubungan antar fungsi, paper ini memberikan fondasi teoretis yang sangat dalam mengenai pemodelan data kode sumber.

**Perbedaan dengan Paper Sebelumnya**
1. **Dibandingkan dengan paper telekomunikasi (misal: Charnkeitkong et al., 1996):** Perbedaannya sangat kontras; paper ini mencari logika program manusia, sedangkan paper telekomunikasi mencari bit data elektronik.
2. **Dibandingkan dengan SCA (Paul & Prakash, 1994) - Versi Konferensi:** Paper tahun 1996 ini adalah versi jurnal yang jauh lebih lengkap, menyediakan studi kasus mendalam tentang metrik dan aliran kontrol yang tidak dibahas secara detail di versi 1994.
3. **Dibandingkan dengan ARDEX (Arima, 1996):** ARDEX menggunakan contoh input-output untuk mencari kode (Programming by Example), sedangkan SCA menggunakan bahasa kueri formal untuk mencari struktur dan logika di dalam database kode.
