# Combinator GP (Briggs & O’Neill, 2008)

*Penelitian ini merumuskan representasi ekspresi kombinator sebagai alternatif sintaksis untuk mendefinisikan ruang pencarian program fungsional bertipe kuat tanpa variabel guna mengoptimasi enumerasi lengkap dan operator genetik pada sistem pemrograman evolusioner.*

**Judul**
Functional genetic programming and exhaustive program search with combinator expressions, International Journal of Knowledge-Based and Intelligent Engineering Systems, IOS Press, 2008

**Penulis**
Forrest Briggs, Melissa O’Neill (Harvey Mudd College, Amerika Serikat)

**Inti Paper**
Paper ini membahas cara menciptakan program komputer secara otomatis menggunakan metode "Genetic Programming" (GP). Biasanya, membuat program fungsional (seperti Lisp atau Haskell) lewat mesin AI sangat sulit karena adanya "variabel" yang rumit dan sering merusak struktur kode. Peneliti mengusulkan penggunaan "ekspresi kombinator" sebagai bahasa representasi kode. Keuntungannya, kombinator tidak membutuhkan variabel sehingga kodenya lebih sederhana dan tidak mudah error saat diacak oleh mesin. Sistem ini memungkinkan komputer untuk melakukan "pencarian program yang menyeluruh" (*exhaustive search*) dengan mendata semua kemungkinan kode hingga ukuran tertentu. Hasil eksperimen menunjukkan bahwa cara ini lebih efektif dibandingkan metode lama dalam membuat program fungsional yang benar.



**Bedah Abstrak Mendetail**
1. **"Using a strongly typed functional programming language for genetic programming has many advantages, but evolving functional programs with variables requires complex genetic operators..."**
   - *Maksud:* Menggunakan bahasa pemrograman fungsional (yang disiplin tipenya ketat) untuk membuat program otomatis punya banyak manfaat, tapi mengelola "variabel" di dalamnya butuh instruksi mesin yang sangat rumit agar program tidak rusak.
2. **"We introduce combinator expressions as an alternative program representation for genetic programming..."**
   - *Maksud:* Peneliti memperkenalkan "ekspresi kombinator" sebagai cara baru untuk menuliskan/mewakili program dalam sistem evolusi otomatis.
3. **"...providing the same expressive power as strongly typed functional programs, but in a simpler format that avoids variables and other syntactic clutter."**
   - *Maksud:* Cara baru ini sama hebatnya dengan bahasa pemrograman fungsional biasa, tapi bentuknya lebih simpel karena membuang variabel dan simbol-simbol yang membingungkan.
4. **"We outline a complete genetic-programming system based on combinator expressions, including a novel generalized genetic operator..."**
   - *Maksud:* Peneliti merancang sistem pemrograman otomatis yang utuh menggunakan kombinator, termasuk cara baru yang unik untuk mengacak atau menyilangkan kode.
5. **"...and also show how it is possible to exhaustively enumerate all well-typed combinator expressions up to a given size."**
   - *Maksud:* Mereka juga menunjukkan cara mendaftarkan semua kemungkinan program yang "sehat" dan benar secara aturan hingga batas ukuran tertentu.
6. **"Our experimental evidence shows that combinator expressions compare favorably with prior representations..."**
   - *Maksud:* Bukti eksperimen membuktikan bahwa representasi kombinator ini bekerja lebih baik dibandingkan cara-cara lama yang pernah ada sebelumnya.
7. **"...and also offers insight into situations where exhaustive enumeration outperforms genetic programming and vice versa."**
   - *Maksud:* Penelitian ini juga memberikan pemahaman kapan teknik mencari satu per satu lebih bagus daripada teknik evolusi acak, dan sebaliknya.

**Baseline**
* **Object Oriented Genetic Programming (Agapitos et al., 2006):** Digunakan sebagai baseline sistem untuk mempelajari fungsi rekursif yang membandingkan efektivitas representasi objek vs representasi fungsional.
* **Performance Enhanced GP (Clack et al., 1997):** Digunakan sebagai baseline untuk teknik peningkatan performa pada sistem pemrograman genetik fungsional awal.
* **Principal Type-Schemes (Damas & Milner, 1982):** Digunakan sebagai acuan dasar untuk sistem pengecekan tipe otomatis (Milner-Damas) guna memastikan program hasil pencarian bersifat "well-typed".
* **Genetic Algorithms for Code Space (Cooper et al., 1999):** Digunakan sebagai baseline perbandingan algoritma genetik dalam mengoptimasi ukuran ruang kode yang dihasilkan.

**Keyword**
Genetic programming, Functional programming, Combinator expressions, Exhaustive program search, Strongly typed languages.

**Kelayakan untuk Riset "CODE SEARCH"**
**LAYAK DENGAN CATATAN (Domain Program Synthesis).**
Paper ini layak dimasukkan jika riset Anda menyentuh ranah **"Program Synthesis"** atau **"Automated Program Search"**—yaitu bagaimana mesin mencari atau menyusun kode baru untuk memecahkan masalah. Namun, jika riset "Code Search" Anda murni tentang *Information Retrieval* (mencari potongan kode yang ditulis manusia di GitHub melalui kueri teks), paper ini mungkin terlalu teknis di sisi logika matematika. Paper ini menjawab pertanyaan: "Bagaimana cara mesin menjelajahi ruang kemungkinan kode secara efisien tanpa variabel?"

**Perbedaan dengan Paper Sebelumnya**
1. **Target Pencarian:** Berbeda dengan paper **Sourcerer (2006)** yang mencari kode buatan manusia, paper ini mencari **kombinasi logika** untuk membangun program baru secara otomatis.
2. **Representasi:** Jika paper **Ohno & Murao (2007)** menggunakan vektor statistik, paper ini menggunakan **ekspresi kombinator** (logika murni) untuk merepresentasikan kode.
3. **Metode:** Dibandingkan dengan **CodeGenie (2007)** yang mencari kode berdasarkan *test case*, paper ini mencari kode melalui **enumerasi lengkap** (mendaftar semua kemungkinan) dan **algoritma evolusioner**.
