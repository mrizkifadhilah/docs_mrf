# MMMF-Code (Weimer et al., 2009)

*Penelitian ini mengadopsi teknik Collaborative Filtering melalui ekstensi model Maximum Margin Matrix Factorization (MMMF) dengan pengenalan dua fungsi kerugian (loss functions) baru untuk mengestimasi probabilitas interaksi biner pada matriks fitur-metode guna menghasilkan rekomendasi pemanggilan API yang akurat.*

**Judul**
Maximum margin matrix factorization for code recommendation, 3rd ACM Conference on Recommender Systems (RecSys'09), ACM, 2009

**Penulis**
Markus Weimer, Alexandros Karatzoglou, Marcel Bruch (Technische Universität Darmstadt, Jerman; LITIS, Prancis)

**Inti Paper**
Paper ini mengusulkan cara cerdas untuk membantu pemrogram belajar menggunakan *framework* atau perpustakaan kode (*library*) dengan lebih cepat. Masalahnya, sistem rekomendasi kode lama biasanya hanya menggunakan aturan sederhana yang kaku. Peneliti mengadaptasi teknologi yang biasa digunakan Netflix atau Amazon untuk menyarankan film (disebut *Collaborative Filtering*), lalu menerapkannya pada kode. Mereka menggunakan metode matematika bernama **Maximum Margin Matrix Factorization (MMMF)**. Bayangkan sebuah tabel raksasa di mana barisnya adalah "potongan kode" dan kolomnya adalah "fungsi API". Sistem ini belajar mengisi tabel tersebut untuk menebak fungsi mana yang kemungkinan besar akan dibutuhkan oleh pemrogram berdasarkan kode yang sudah ia tulis. Hasilnya terbukti jauh lebih akurat dibandingkan sistem berbasis aturan tradisional.



**Bedah Abstrak Mendetail**
1. **"Code recommender systems ease the use and learning of software frameworks and libraries by recommending calls based on already present code."**
   - *Maksud:* Sistem rekomendasi kode mempermudah penggunaan dan pembelajaran kerangka kerja serta perpustakaan perangkat lunak dengan cara menyarankan pemanggilan fungsi berdasarkan kode yang sudah ada.
2. **"Typically, code recommender tools have been based on rather simple rule based systems while many of the recent advances in Recommender Systems and Collaborative Filtering have been largely focused on rating data."**
   - *Maksud:* Biasanya, alat rekomendasi kode hanya berbasis aturan sederhana, sementara kemajuan teknologi rekomendasi saat ini lebih banyak fokus pada data penilaian (rating), bukan pada struktur kode.
3. **"In this paper, we extend state-of-the-art collaborative filtering technology, namely Maximum Margin Matrix Factorization (MMMF) to this interesting application domain and show how to deal with the challenges posed by this problem."**
   - *Maksud:* Peneliti mengembangkan teknologi *collaborative filtering* tercanggih (MMMF) untuk diterapkan pada dunia pengodean dan menunjukkan cara mengatasi tantangan unik di bidang ini.
4. **"To this end, we introduce two new loss functions to the MMMF model."**
   - *Maksud:* Untuk mencapai hal itu, peneliti menciptakan dua rumus perhitungan kesalahan (loss functions) baru agar model matematika tersebut lebih akurat dalam menebak kebutuhan kode.
5. **"While we focus on code recommendation in this paper, our contributions and the methodology we propose can be of use in almost any collaborative setting that can be represented as a binary interaction matrix."**
   - *Maksud:* Meskipun fokus pada kode, metode ini bisa digunakan untuk sistem apa pun yang datanya bisa digambarkan dalam tabel interaksi ya/tidak (matriks biner).
6. **"We evaluate the algorithm on real data drawn from the Eclipse Open Source Project."**
   - *Maksud:* Peneliti menguji algoritma ini menggunakan data nyata dari proyek sumber terbuka Eclipse.
7. **"The results show a significant improvement over current rule-based approaches."**
   - *Maksud:* Hasilnya menunjukkan peningkatan performa yang sangat besar dibandingkan dengan cara-cara lama yang berbasis aturan.

**Baseline**
* **FrUiT (Bruch, 2006):** Digunakan sebagai baseline sistem pendukung IDE untuk memahami *framework* yang menggunakan pendekatan pencocokan berbasis aturan/statistik sederhana.
* **MMMF Original (Srebro, 2005):** Digunakan sebagai baseline model dasar *Maximum Margin Matrix Factorization* sebelum dimodifikasi dengan fungsi kerugian baru untuk data kode.
* **Weighted Logistic Regression (Lee, 2003):** Digunakan sebagai baseline perbandingan untuk teknik pembelajaran dari contoh positif dan data tanpa label dalam konteks interaksi biner.

**Keyword**
Collaborative filtering, Matrix factorization, Code recommendation, Maximum margin, Loss functions.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK (Konteks Recommendation-as-Search).**
Paper ini sangat relevan jika riset Anda memandang **Code Search** sebagai masalah **rekomendasi**. Seringkali pengembang melakukan pencarian kode karena mereka tidak tahu fungsi API apa yang harus dipanggil selanjutnya. Teknik *Matrix Factorization* dalam paper ini memberikan alternatif cerdas untuk *Information Retrieval* tradisional: alih-alih mencocokkan kata kunci teks, sistem ini mencocokkan "perilaku" atau "pola penggunaan" antar pengembang. Ini adalah rujukan kunci untuk riset *Code Search* berbasis graf atau interaksi.

**Perbedaan dengan Paper Sebelumnya**
1. **Model Matematika:** Berbeda dengan paper **Sourcerer (2009)** yang mengandalkan indeksasi teks dan struktur, paper ini menggunakan **faktorisasi matriks** (aljabar linier) untuk menemukan hubungan tersembunyi antar kode.
2. **Input Pengguna:** Jika paper **SNIFF (2009)** membutuhkan kueri bahasa alami, paper ini bekerja secara **implisit** dengan melihat kode yang sedang diketik pengembang sebagai kuerinya.
3. **Sifat Prediksi:** Dibandingkan dengan **MAPO (2009)** yang menambang pola urutan API yang sering muncul, paper ini mampu merekomendasikan kode yang mungkin belum pernah muncul bersamaan secara langsung tetapi memiliki kemiripan laten (*latent features*).
