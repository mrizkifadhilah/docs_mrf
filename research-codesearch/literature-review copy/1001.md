# SCA (Paul & Prakash, 1994)

*Penelitian ini merumuskan kerangka formal Source Code Algebra (SCA) yang memanfaatkan struktur many-sorted algebra untuk mendefinisikan model data dan bahasa kueri aljabar guna mengoptimalkan ekspresivitas serta performa sistem temu kembali kode sumber.*

**Judul**
Querying source code using an algebraic query language, Proceedings of the International Conference on Software Maintenance (ICSM), IEEE Computer Society, 1994

**Penulis**
Santanu Paul (University of Michigan), Atul Prakash (University of Michigan)

**Inti Paper**
Paper ini menyoroti keterbatasan sistem pencarian kode tradisional yang dianggap kurang memiliki landasan formal dan kemampuan kueri yang terbatas untuk proyek skala besar. Peneliti memperkenalkan **Source Code Algebra (SCA)**, sebuah kerangka kerja formal yang memodelkan kode sumber sebagai objek aljabar. SCA menyediakan model data yang memungkinkan kode program direpresentasikan secara terstruktur, bahasa kueri berbasis ekspresi aljabar yang kuat, serta teknik optimasi kueri untuk meningkatkan kinerja pencarian. Dengan pendekatan ini, pengembang dapat melakukan analisis interaktif dan pemahaman program (*program understanding*) yang lebih mendalam, seperti melacak ketergantungan antar fungsi atau mencari pola arsitektur tertentu dalam basis kode yang masif.



**Baseline**
* **The C Information Abstraction System (CIA) (Chen et al., 1990):** Digunakan sebagai baseline untuk sistem ekstraksi entitas kode yang menggunakan model relasional, di mana SCA menawarkan model aljabar yang lebih ekspresif untuk menangani struktur data yang kompleks.
* **Relational Model of Data (Codd, 1970):** Digunakan sebagai dasar teori perbandingan; peneliti menunjukkan bahwa aljabar relasional standar kurang efektif dalam memodelkan hirarki kode sumber jika dibandingkan dengan *many-sorted algebra* pada SCA.
* **Concept Assignment Problem (Biggerstaff, 1993):** Digunakan sebagai baseline metodologi dalam konteks *program understanding* untuk menunjukkan bagaimana kueri aljabar dapat membantu mengidentifikasi konsep tingkat tinggi dalam kode.

**Keyword**
Source Code Algebra, Query language, Reverse engineering, Program understanding, Many-sorted algebra, Query optimization.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini adalah referensi fundamental untuk riset **Code Search** Anda. Berbeda dengan paper-paper sebelumnya yang hanya menggunakan istilah "search" untuk bit biner, paper ini secara spesifik membangun sistem untuk mencari fungsionalitas di dalam **source code**. Ini memberikan landasan teoritis tentang bagaimana mesin pencari kode harus mengorganisir data (model aljabar) agar pencarian tidak hanya sekadar mencocokkan teks (*string matching*), melainkan memahami hubungan antar komponen kode.

**Perbedaan dengan Paper Sebelumnya**
1. **Domain:** Ini adalah paper murni *Software Engineering*, berbeda dengan paper telekomunikasi (Pietrobon, Ogiwara, dll.) yang mencari sinyal elektronik.
2. **Fokus:** Paper ini fokus pada **algebraic retrieval** (pencarian berbasis logika matematika), sedangkan paper **SCRUPLE** fokus pada **pattern matching** (pencocokan pola tekstual/struktural).
3. **Objektivitas:** Paper ini bertujuan memecahkan masalah kompleksitas pemeliharaan perangkat lunak, sementara paper teknik lainnya berfokus pada bit error rate atau transmisi data.
