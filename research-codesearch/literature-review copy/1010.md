# Kima (Ajiro & Ueda, 2002)

*Sistem ini mengintegrasikan analisis statis berbasis konstrain dan inferensi tipe/mode otomatis untuk melakukan lokalisasi kesalahan serta koreksi otomatis pada program logika konkuren melalui minimal inconsistent subsets.*

**Judul**
Kima: An automated error correction system for concurrent logic programs, Automated Software Engineering, Kluwer Academic Publishers (Springer), 2002

**Penulis**
Yasuhiro Ajiro (Waseda University), Kazunori Ueda (Waseda University)

**Inti Paper**
Paper ini memperkenalkan sebuah sistem bernama **Kima** yang dapat memperbaiki kesalahan penulisan kode sumber secara otomatis. Fokus utamanya adalah pada program logika konkuren (program yang menjalankan banyak proses secara bersamaan). Kima bekerja tanpa memerlukan deklarasi manual dari programmer; ia menggunakan "analisis konstrain" untuk mendeteksi ketidakkonsistenan logika, seperti variabel yang salah tempat. Sistem ini mencari kumpulan kecil aturan yang saling bertabrakan untuk menentukan sumber eror. Setelah sumber ditemukan, Kima mencoba mengganti simbol-simbol di sekitar area tersebut secara sistematis dan menguji kembali apakah kodenya sudah benar. Karena proses pencariannya dibatasi pada area sumber eror saja, jumlah saran perbaikan yang diberikan sangat sedikit namun akurat.



**Baseline**
* **Error-correcting source code (Ajiro et al., 1998):** Digunakan sebagai baseline awal yang meletakkan dasar teori penggunaan konstrain mode untuk diagnosis kesalahan pada program logika.
* **Soft typing with conditional types (Aiken et al., 1994):** Digunakan sebagai baseline untuk sistem pengetikan (typing) yang lebih fleksibel tanpa memerlukan deklarasi eksplisit untuk mendeteksi kesalahan tipe.
* **Explaining type errors in polymorphic languages (Beaven et al., 1993):** Digunakan sebagai baseline pembanding dalam hal kemampuan sistem menjelaskan alasan terjadinya kesalahan tipe (*type error*) kepada pengguna.
* **A portable and efficient implementation of KL1 (Chikayama et al., 1994):** Digunakan sebagai baseline implementasi bahasa KL1 yang menjadi target operasional sistem Kima dalam mengeksekusi program logika konkuren.

**Keyword**
Concurrent logic programming, Automated error correction, Constraint satisfaction, Static analysis, Program debugging, Kima.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Meskipun tujuan akhirnya adalah *debugging*, paper ini sangat relevan bagi riset "Code Search" karena menggunakan teknik **Search Space Pruning** (pemangkasan ruang pencarian). Kima menunjukkan bagaimana analisis statis dan konstrain dapat digunakan untuk mempersempit ruang pencarian saat mencoba menemukan potongan kode yang "benar" atau "diinginkan" di antara banyak alternatif. Konsep pencarian perbaikan kode berbasis semantik program ini adalah salah satu cabang penting dalam pengembangan mesin pencari kode yang lebih cerdas dan proaktif.

**Perbedaan dengan Paper Sebelumnya**
1. **Versi Implementasi:** Paper ini adalah versi yang lebih matang dan lengkap dari paper **Error-correcting source code (Ajiro et al., 1998)** yang Anda rangkum sebelumnya. Jika paper 1998 hanya fokus pada teori dasar, paper 2002 ini memperkenalkan sistem utuh bernama **Kima** dan menyertakan eksperimen kuantitatif.
2. **Domain vs. Teknik:** Berbeda dengan paper-paper telekomunikasi (seperti **Low-Rate Turbo**) yang mencari bit sinyal, paper ini mencari **simbol program**.
3. **Optimasi:** Paper ini menambahkan berbagai teknik optimasi untuk memastikan pencarian perbaikan kode tetap efisien secara waktu komputasi, sesuatu yang belum dibahas mendalam di paper-paper biologi atau fisika yang sebelumnya Anda baca.
