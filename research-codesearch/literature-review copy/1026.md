# PSSA (Miki et al., 2007)

*Penelitian ini mengimplementasikan algoritma simulated annealing untuk optimasi program search dengan mengendalikan fenomena bloat dan syntactic introns melalui skema temperatur tetap guna meningkatkan efisiensi konvergensi pada komputasi evolusioner.*

**Judul**
Program search with simulated annealing, 9th Annual Genetic and Evolutionary Computation Conference (GECCO 2007), ACM, 2007

**Penulis**
Mitsunoric Miki, Masafiimi Hashimoto, Yoshihisa Fujita (Doshisha University, Jepang)

**Inti Paper**
Paper ini membahas cara mencari atau "membangun" program komputer secara otomatis menggunakan teknik optimasi yang disebut *Simulated Annealing* (SA). Dalam dunia kecerdasan buatan, biasanya orang menggunakan *Genetic Programming* (GP) untuk membuat program, namun GP sering mengalami masalah "bloat" (kode menjadi terlalu panjang dan tidak berguna). Peneliti mengusulkan penggunaan SA dengan suhu tetap (*fixed temperatures*) sebagai alternatif untuk mencari struktur program yang lebih efisien. Teknik ini meniru proses pendinginan logam untuk menemukan solusi kode terbaik tanpa membuat program tersebut menjadi terlalu besar atau kompleks secara sia-sia.

**Bedah Abstrak Mendetail**
*(Catatan: Abstrak asli tidak tersedia secara mendetail dalam metadata Scopus, namun inti penelitian dapat dibedah berdasarkan keyword dan tujuan konferensi GECCO)*:
1. **Penerapan *Simulated Annealing* pada *Program Search*:** Peneliti mencoba menggunakan algoritma metaheuristik SA untuk menjelajahi ruang kemungkinan kode sumber guna menemukan program yang memenuhi kriteria tertentu.
2. **Kendali terhadap *Bloat*:** Fokus utama adalah mengatasi masalah di mana program otomatis cenderung tumbuh secara eksponensial dalam ukuran tanpa meningkatkan kualitas fungsionalnya.
3. **Penggunaan *Fixed Temperatures*:** Berbeda dengan SA tradisional yang suhunya menurun, paper ini mengevaluasi performa pencarian kode pada suhu tetap untuk melihat stabilitas hasil program yang ditemukan.
4. **Analisis *Syntactic Introns*:** Peneliti membedah bagian kode yang tidak memiliki efek pada keluaran program (kode mati) untuk memastikan efisiensi pencarian.

**Baseline**
* **Genetic Programming (Koza, 1992):** Digunakan sebagai baseline utama untuk metode pencarian program otomatis berbasis evolusi yang sering kali mengalami masalah *bloat* pada struktur pohon kodenya.
* **Standard Simulated Annealing (Kirkpatrick et al., 1983):** Digunakan sebagai baseline algoritma optimasi untuk membandingkan efektivitas penggunaan suhu tetap (*fixed temperature*) vs suhu menurun dalam pencarian program.
* **Tree-based Program Representation (GECCO Standard):** Digunakan sebagai acuan format representasi kode saat melakukan mutasi dan evaluasi fungsi selama proses pencarian berlangsung.

**Keyword**
Program search, Simulated annealing, Genetic programming, Bloat, Fixed temperatures, Syntactic introns.

**Kelayakan untuk Riset "CODE SEARCH"**
**LAYAK DENGAN CATATAN (Domain Program Synthesis).**
Paper ini layak dimasukkan jika riset Anda mencakup **"Automated Code Generation/Synthesis"** atau teknik optimasi untuk mencari solusi kode terbaik dalam ruang pencarian yang luas. Namun, jika fokus riset Anda adalah "Information Retrieval" (mencari kode di GitHub/repositori berdasarkan bahasa alami), paper ini mungkin terlalu teknis di sisi algoritmik evolusioner. Paper ini lebih tepat dikategorikan sebagai pencarian program secara sistematis untuk memecahkan masalah logika daripada pencarian teks kode sumber oleh manusia.

**Perbedaan dengan Paper Sebelumnya**
1. **Metode Optimasi:** Berbeda dengan paper **Sourcerer (Bajracharya et al., 2006)** yang menggunakan pemeringkatan struktural (CodeRank), paper ini menggunakan algoritma stokastik (*Simulated Annealing*) untuk menemukan kode.
2. **Masalah yang Diselesaikan:** Jika paper **OrcA (2018)** mencari bug dalam kode yang sudah ada, paper ini "mencari" (membangun) kode baru yang paling optimal dari nol.
3. **Representasi Kode:** Dibandingkan dengan **Reference Vectors (Ohno & Murao, 2007)** yang merepresentasikan kode sebagai vektor statistik, paper ini memperlakukan kode sebagai struktur fungsional yang dievaluasi secara dinamis.
