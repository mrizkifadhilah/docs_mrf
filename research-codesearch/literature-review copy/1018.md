# CodeQuest (Hajiyev et al., 2006)

*Sistem ini mengimplementasikan pemetaan bahasa logika safe Datalog ke dalam skema basis data relasional guna mengeksekusi kueri rekursif pada struktur kode sumber yang masif dengan optimasi translasi SQL.*

**Judul**
CodeQuest: Scalable source code queries with datalog, Lecture Notes in Computer Science (LNCS), Springer-Verlag, 2006

**Penulis**
Elnar Hajiyev, Mathieu Verbaere, Oege de Moor (University of Oxford, Inggris)

**Inti Paper**
Paper ini memperkenalkan **CodeQuest**, sebuah alat bantu bagi pemrogram untuk mencari dan mengeksplorasi hubungan antar bagian dalam kode program yang berukuran sangat besar. Masalah utamanya adalah alat pencari tradisional sering kali lambat atau tidak bisa menangani hubungan yang kompleks (seperti: "cari semua fungsi yang memanggil fungsi X secara langsung maupun tidak langsung"). CodeQuest menggabungkan keunggulan bahasa logika (**Datalog**) yang sangat ekspresif dengan kekuatan penyimpanan data (**Database Relasional**). Dengan sistem ini, pemrogram bisa melakukan pencarian yang sangat mendalam dan teknis secara cepat dan efisien karena sistem ini otomatis mengubah kueri logika menjadi bahasa database (SQL) yang sudah dioptimalkan.



**Bedah Abstrak Mendetail**
1.  **"Source code querying tools allow programmers to explore relations between different parts of the code base."**
    * *Maksud:* Penulis menjelaskan fungsi dasar alat pencari kode, yaitu membantu pengembang melihat keterkaitan antar bagian kode (misalnya, koneksi antar kelas atau fungsi).
2.  **"This paper describes such a tool, named CodeQuest. It combines two previous proposals, namely the use of logic programming and database systems."**
    * *Maksud:* Peneliti memperkenalkan alat mereka, CodeQuest, yang menggabungkan dua teknologi: pemrograman logika (untuk aturan pencarian yang cerdas) dan sistem database (untuk menangani data dalam jumlah besar).
3.  **"As the query language we use safe Datalog, which was originally introduced in the theory of databases."**
    * *Maksud:* Bahasa kueri yang digunakan adalah Datalog. Datalog dipilih karena sangat kuat dalam logika namun tetap aman digunakan dalam lingkungan database.
4.  **"That provides just the right level of expressiveness; in particular recursion is indispensable for source code queries."**
    * *Maksud:* Datalog memberikan kemampuan pencarian yang pas. Fitur "rekursi" (kemampuan mencari hubungan berantai tanpa henti) sangat diperlukan untuk memahami struktur kode program.
5.  **"Safe Datalog is like Prolog, but all queries are guaranteed to terminate, and there is no need for extra-logical annotations."**
    * *Maksud:* Datalog mirip dengan bahasa Prolog, namun lebih aman karena pencarian dijamin akan selesai (tidak akan *hang* atau *looping* selamanya) tanpa perlu tambahan kode yang rumit.
6.  **"Our implementation of Datalog maps queries to a relational database system."**
    * *Maksud:* Secara teknis, setiap permintaan pencarian dalam Datalog akan diterjemahkan menjadi bahasa yang dimengerti oleh database relasional (seperti SQL).
7.  **"We are thus able to capitalise on the query optimiser provided by such a system."**
    * *Maksud:* Dengan menggunakan sistem database, CodeQuest bisa memanfaatkan fitur penghemat waktu (optimiser) yang sudah tersedia di database tersebut agar pencarian menjadi kilat.
8.  **"For recursive queries we implement our own optimisations in the translation from Datalog to SQL."**
    * *Maksud:* Khusus untuk pencarian yang berantai (rekursif), peneliti membuat cara khusus agar proses penerjemahan dari Datalog ke SQL menjadi jauh lebih efisien.
9.  **"Experiments confirm that this strategy yields an efficient, scalable code querying system."**
    * *Maksud:* Hasil uji coba membuktikan bahwa CodeQuest mampu bekerja dengan sangat cepat dan tetap stabil meskipun digunakan pada proyek program yang ukurannya sangat raksasa.

**Baseline**
* **JQuery (Eclipse Foundation):** Digunakan sebagai baseline alat pencarian kode berbasis logika yang terintegrasi dengan Eclipse IDE, namun memiliki keterbatasan dalam skalabilitas pada dataset besar.
* **XSB / Tyruba (De Volder, 1998):** Digunakan sebagai baseline sistem *metaprogramming* berbasis logika untuk membandingkan efisiensi eksekusi kueri pada struktur data kode yang kompleks.
* **Foundations of Databases (Abiteboul et al., 1995):** Digunakan sebagai landasan teori untuk kriteria keamanan (*safety*) dan terminasi pada bahasa Datalog yang diimplementasikan.
* **abc Compiler (Avgustinov et al., 2005):** Digunakan sebagai konteks pengujian pada kompilator AspectJ untuk melihat kemampuan sistem dalam memproses struktur kode berorientasi objek yang dinamis.

**Keyword**
CodeQuest, Datalog, Source code querying, SQL translation, Relational database, Recursive queries, Scalability.

**Kelayakan untuk Riset "CODE SEARCH"**
**SANGAT LAYAK.**
Paper ini adalah literatur wajib jika riset Anda menyentuh aspek **Structural Code Search** (pencarian berdasarkan struktur/logika, bukan sekadar keyword). CodeQuest menawarkan solusi atas masalah performa yang sering muncul ketika melakukan pencarian kode pada repositori skala besar. Teknik pemetaan logika ke SQL adalah pendekatan arsitektural yang sangat kuat untuk membangun mesin pencari kode yang skalabel dan formal.

**Perbedaan dengan Paper Sebelumnya**
1.  **Bahasa Kueri:** Berbeda dengan paper **Component Search (Washizaki & Fukazawa, 2004)** yang menggunakan kata kunci sederhana, CodeQuest menggunakan bahasa logika formal (Datalog) yang jauh lebih presisi.
2.  **Skalabilitas:** Jika paper **Kima (Ajiro & Ueda, 2002)** fokus pada perbaikan bug pada skala kecil, paper ini fokus pada **skalabilitas** (kemampuan menangani jutaan baris kode) menggunakan optimasi database relasional.
3.  **Metode Temu Kembali:** Dibandingkan dengan **combinFormation (Kerne et al., 2003)** yang bersifat eksploratif visual, CodeQuest bersifat analitis-struktural yang ditujukan untuk pencarian fakta-fakta spesifik dalam arsitektur perangkat lunak.
